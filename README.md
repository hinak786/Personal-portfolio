# Hina Khoja — Professional Portfolio

A professional portfolio highlighting my background in clinical research,
neuroscience, education, and interest in artificial intelligence in healthcare.

Built with HTML, CSS, and JavaScript.

## Website sections

- About: professional background and areas of focus.
- Resume: education and skills.
- Portfolio: oncology laboratory research and clinical research coordination.

## Open the website locally

1. Download this repository using Code → Download ZIP.
2. Extract the entire ZIP.
3. Keep index.html and the assets folder together.
4. Open index.html in a browser.

No installation or build command is required. Internet access is needed
for externally hosted fonts and icons.
